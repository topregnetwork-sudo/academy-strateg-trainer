# Одно обновление существующего моста

Не создавайте новый Apps Script проект. Откройте прежний проект моста.

1. Сохраните текущую версию развёртывания для отката.
2. Замените содержимое `Код.gs` содержимым соседнего файла `Code.gs` и сохраните.
3. «Начать развертывание» → «Управление развертываниями» → существующее веб-приложение → значок карандаша → «Версия: Новая версия» → «Развернуть».
4. Адрес веб-приложения, аккаунт выполнения, доступ и `BRIDGE_SECRET` не меняйте. Секреты никому присылать не нужно.
5. Сообщите «Мост 047 обновлён». После проверки поддержки нового бланка можно активировать подготовленную серверную часть.

Пока серверный флаг GOOGLE_DRIVE_INTERVIEW_SHEET_047 выключен, текущий поток работает по прежней схеме. Обновление моста само по себе не рассылает сообщений и не меняет кандидатов.
