# Мост 049 — совместимость и сроки этапов

Откройте существующий проект в https://script.google.com/home .

1. Замените содержимое Код.gs файлом Code.gs из этой папки целиком.
2. Сохраните.
3. Начать развертывание → Управление развертываниями → прежнее веб-приложение → карандаш.
4. Версия → Новая версия → Развернуть.

Адрес, секрет и доступ оставьте прежними. Новый проект не нужен. Сохраните номер предыдущей версии для отката. После публикации напишите «Мост 049 обновлён».

049 добавляет поддержку старого названия строки даты и автоматическую запись сроков по событиям. Версии 047/048 продолжают поддерживаться. Публикация сама не меняет кандидатов, не запускает рассылку и не переключает сервер. Затем Codex проверяет timeline049, один существующий бланк и включает подготовленную серверную часть.
