# Обновление связи записи с бланком

Открыть прежний проект Apps Script моста. Заменить только Код.gs содержимым соседнего Code.gs.
Сохранить → Начать развертывание → Управление развертываниями → существующее веб-приложение → карандаш → Новая версия → Развернуть.

Адрес, права доступа и BRIDGE_SECRET оставить прежними. Нового проекта не создавать. Предыдущий номер версии сохранить для точечного отката.

Чистый шаблон последней структуры подготовлен: https://docs.google.com/spreadsheets/d/1t9lAc_Pc5EtJaR641EjbJTqqLdb103riF0yslSl3rNE/edit . Код сохраняет совместимость с 047 и не переделывает старые заполненные файлы.

После публикации написать «Мост 048 обновлён». Проверить capability interviewSheet048 и appointment048, выполнить точечный пробный вызов, завершить событийный импорт сроков. Только затем выпускать серверную часть и включать INTERVIEW_APPOINTMENT_048=true. Одно обновление моста не запускает рассылки и не меняет анкеты. Не менять адрес, доступ, секрет или создавать новое развертывание.
