# Пульт воронки: короткая инструкция

Откройте https://academy-strateg-trainer.vercel.app/operator.html и войдите прежним кодом. Обновите страницу, если блок не появился.

## Отправить следующий шаг

1. Откройте «Управление воронкой». При первом открытии программа назначит точные таймеры существующим будущим Zoom-записям. Если возникает ошибка, она покажется здесь; старый механизм не отключается до успешного перехода.
2. Отфильтруйте людей как обычно. Поставьте галочки у нужных кандидатов. «Выбрать видимых» выбирает только текущий список, «Снять выбор» очищает все галочки.
3. Выберите исходный шаблон или сохранённую версию и действие. «Только сообщение» не меняет этап. Для приглашения после Теста 1 выберите встречу.
4. Отредактируйте текст, названия кнопок и ссылки/ответы. Приглашение содержит кнопки целей, PDF и времени автоматически. Формат текста — обычный текст без HTML.
5. Если хотите сохранить изменение для будущего, нажмите «Сохранить версию». Иначе это только текст текущей отправки. Предыдущие версии не удаляются.
6. Для проверки кнопок нажмите «Отправить тест мне». Это сообщение только @HRAcademyStrateg; тестовые кнопки не меняют запись и статус.
7. «Проверить получателей» покажет имена, города, исключённых и пример текста. Только после проверки нажмите «Отправить именно этим … кандидатам».
8. Можно закрыть панель. Результат смотрите в журнале, кнопка «Обновить настройки и журнал». Сводка придёт в Координацию.

Надежда Волкова, финалисты и принятые сотрудники защищены от завершающих действий. Приглашения после теста разрешены только завершившим Тест 1, для города выбранной встречи, без повторного приглашения на ту же встречу. Новые изменения этапа после предпросмотра требуют повторной проверки.

## Назначить время

В правой части создайте встречу: название, город, онлайн/офлайн, дата, начало и конец, шаг, места, адрес/ссылка, за сколько закрыть запись и напомнить. Время — UTC+3 (Минск/Москва).

«Создать встречу» ничего не отправляет. Затем выберите её в приглашении слева. Если нужна другая конфигурация, создайте новую встречу; существующие записи не переписываются. Для прекращения новых записей нажмите «Закрыть запись»; это также подавляет напоминания этой новой встречи. Отмену сообщите участникам отдельным выбранным сообщением — закрытие не уведомляет их само.

После выбора кандидатом времени: место фиксируется → подтверждение кандидату → бриф и сводка в Координации → точное напоминание. При переносе прежнее место сохраняется, пока новое не занято. «Участники» показывает записи; «Анкета и чат» открывает прежнюю карточку без сброса данных. Кнопки исторической встречи 1 сентября работают отдельно как раньше.

## Ошибки и повтор

«Продолжить неотправленных» запускает только ещё ожидающих получателей. Это не повтор всей рассылки. Если результат отправки неизвестен (например, соединение оборвалось после передачи Telegram), программа не отправляет снова автоматически. Журнал показывает получателя и причину; сначала проверьте реальный диалог. Доставленные сообщения не дублируются.

Обычный выпадающий статус в карточке — ручная коррекция без автоматической рассылки. Решение с сообщением выполняйте через пульт.

Откат: попросите «Откати FUNNEL-CONSOLE-032, сохрани кандидатов, данные и сообщения». Код откатывается отдельно от внешних действий. Уже доставленное сообщение или удалённая служебная строка не возвращаются автоматически. Новые таблицы остаются для истории.
