# Как отслеживать кандидатов — аудит 30 августа 2026

## Исправленный порядок PRODUCTIVITY-ORDER-034

Тест 1 заполнен (сбор данных) → интервью на продуктивность → продуктивность пройдена → расшифровка Теста 1 → дальнейшее решение.
После заполнения теста приглашайте на продуктивность, а не проверяйте расшифровку как условие приглашения. После успешного интервью установите «Продуктивность пройдена — расшифровать Тест 1». По завершении расшифровки — «Тест 1 расшифрован».
Это уточнение заменяет прежние указания ниже о проверке результата перед приглашением. Подтверждение заполнения для новых кандидатов больше не обещает IQ следующим шагом. Исторические сообщения остаются прежними.

Проверен код опубликованной версии bfb0d45. Это схема реально реализованных переходов, а не обещание проверки доставки всем кандидатам. Персональная база и Telegram в этом аудите напрямую недоступны; скриншоты не заменяют полный журнал.

## Схема

| Событие | Что получает кандидат | Что видит оператор / следующий шаг |
|---|---|---|
| Первая анкета → запуск бота | Без опыта, отдельные занятия, менее года — выбор первичного Zoom; год и более — ответ без слотов | Опыт, первая анкета, журнал. Повторная анкета не должна сбрасывать этап |
| Нажатие времени Zoom | Подтверждение даты/времени, кнопка Zoom | Первичная запись. Бриф в «Тренеры собеседования» |
| За 30 минут | Напоминание Zoom | Общий бриф по дате и слоту |
| Через 90 минут, не подтверждено участие | Предложение выбрать другое время / отказаться; с проверкой членства | Не путать старую дату Zoom с новой встречей продуктивности |
| «кандидат» после Zoom | Кнопки группы и Анкеты 2 | Этап Анкета 2 / Тест 1. Кодовое слово, а не нажатие Zoom, открывает продолжение |
| Анкета 2 заполнена | Подтверждение, указание изучать материалы группы | Дата заполнения Анкеты 2; тест не выдаётся сразу этим событием |
| «тест» | Если Анкета 2 не заполнена — её ссылка; иначе персональный Тест 1 | Отправка ссылки не равна заполнению |
| 200 ответов Теста 1 сохранены | Подтверждение заполнения; повторный «тест» сообщает, что ответы уже сохранены | Проверка результата оператором, создание папки Drive при готовой Анкете 2 |
| Оператор выбрал встречу и отправил приглашение | Цели, PDF, выбор свободного времени | Отдельный журнал отправки; одно изменение статуса ничего не отправляет |
| Кандидат выбрал продуктивность | Подтверждение и изменение времени | Бриф и сводка в Координации; точное напоминание для новых встреч |
| Решение: финал | Утверждённое сообщение и настроенные кнопки | Финал; ответ в Координации |
| Решение: не прошёл | Сообщение с Да/Нет о дальнейшем взаимодействии | Ожидание ответа — отдельный этап |
| Ответ Да / Нет | Соответствующее завершение | Контакт Академии / Отбор завершён, выход из рабочей группы |

## Каждый день — короткий алгоритм

1. Выберите город и этап. Старый фильтр «Дата Zoom» относится только к первичной встрече.
2. Откройте кандидата. Вверху карточки есть «Движение кандидата»: Анкета 2, Тест 1, отправка приглашения и будущая запись отдельно.
3. Если есть входящее после последнего ответа — прочитайте его. Это сигнал проверить диалог, не доказательство ошибки бота.
4. «Заполнено» + нет приглашения: откройте результат и примите решение. Не просите проходить заново только из-за названия статуса.
5. Для приглашения: галочка → Управление воронкой → действие → встреча нужного города → текст → Проверить получателей → Отправить.
6. Проверьте журнал: черновик/ожидание/обработка НЕ означают доставку. «Требует проверки» не пересылайте вслепую.
7. Отправлено, но время не выбрано: проверьте актуальность даты приглашения; это не записанный кандидат.
8. Время выбрано: смотрите «Участники встречи» в пульте и бриф в Координации, не старую дату Zoom слева.
9. Обычный выпадающий статус — ручная коррекция БЕЗ сообщения. Для решения с сообщением используйте действие пульта.

## Статусы

Названия уточнены: первичный Zoom отделён от продуктивности; «Анкета» заменена на «Анкета 2 / Тест 1»; заполнение теста отделено от проверки; «не прошёл — ожидается ответ» отделено от завершённого отбора. Обучение, стажировка, принят и контакт вынесены в группу «После отбора» фильтра. Технические значения не удалены: на них завязаны существующие кнопки и сохранённые кандидаты.

Стадии «Анкета 2 отправлена / заполнена», «Тест 1 отправлен / заполнен» отображаются по фактическим датам в карточке, без дополнительных вручную поддерживаемых статусов. Не добавлены фиктивные этапы «IQ пройден» и «воспроизведение пройдено»: их результаты пока не автоматизированы.

## Найденные пробелы и границы

- В подтверждении Теста 1 всё ещё обещан IQ-тест. Отдельной выдачи IQ/воспроизведения код не реализует. Исторические сообщения и утверждённый текст этим UI-изменением не переписаны.
- Завершение теста запускает подтверждение и Drive, но не универсальное приглашение. Приглашение — отдельное действие оператора. Это не полностью безручная воронка после теста.
- Кампания 1 сентября — отдельная прежняя реализация только для Минска; она не распространяется на Челябинск. Создание новой встречи само по себе не рассылает приглашения.
- Слова «время» и «тест 2» не являются командами выбора слотов. Время выбирается кнопкой; «тест» — предусмотренная команда Теста 1.
- Старые сообщения хранят текст и тип, но не полный снимок кнопок. Панель объясняет тип сообщения; не выдумывает старые ссылки или наличие свободного времени.
- «Принято Telegram» не означает прочитано. Отсутствующая запись не является абсолютным доказательством отсутствия доставки при старых ошибках сохранения истории.
- Точные Zoom-таймеры включаются после успешного переноса через новый пульт; наличие флага в production в этом аудите не проверено.
- Ульяна на скриншоте из Челябинска. Видны Тест 1 и ответ «уже заполнен». Приглашение на следующую встречу по скриншоту не доказано. Полный ответ даёт новый блок карточки и журнал.

## Что исправлено CANDIDATE-VISIBILITY-033

Наложение имени и даты: строки списка теперь одноколоночные. Карточка показывает факты этапов и журнал приглашений; новые данные читаются только по выбранному кандидату. Ошибка чтения журнала обозначается явно и не скрывает переписку. Сообщения помечены назначением, доставка названа корректно. Сама автоматизация и данные не изменены.

Откат: «Откати CANDIDATE-VISIBILITY-033, сохрани данные и воронку».
