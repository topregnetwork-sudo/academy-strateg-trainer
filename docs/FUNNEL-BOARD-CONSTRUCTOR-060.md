# Конструктор доски и карточек — 060

## Назначение

Доска — это компактное представление текущего состояния кандидатов. Она не переписывает историю и не запускает фоновый перебор воронки.

## Неподвижный формат карточки

Каждая карточка состоит ровно из двух визуальных строк:

1. Имя и фамилия. Имя является ссылкой на бланк интервью на продуктивность, если бланк уже создан.
2. Город · время слота · срок на текущем этапе · маленькая отметка действия.

Справа у карточки находятся только две компактные кнопки: открыть подробную карточку и открыть Telegram. Они не добавляют новые строки.

## Правила действий

- Кнопки результата продуктивности показываются только для просроченной записи на продуктивность.
- «Прошёл» и «Не прошёл» меняют статус и сохраняют событие результата.
- После выбора результата сообщение кандидату не отправляется автоматически, пока шаблон не утверждён.
- Вместо отправки создаётся одна внутренняя отметка «сообщение подготовлено к отправке» (`productivity_message_pending`).
- Повторное нажатие не создаёт новый результат или новую отметку.
- Отправка утверждённого текста — отдельное действие оператора по точному списку получателей.

## Правила колонок и конверсии

- Название, порядок и набор статусов колонки берутся из настроек этапов.
- Новые колонки добавляются только через настройку этапов; существующие статусы и история не меняются.
- Конверсия считается по текущему набору фильтров и показывает, сколько кандидатов дошло до этапа.
- На широком экране ширина колонок распределяется динамически; на узком экране доска прокручивается горизонтально.
- Группировка внутри колонки не создаёт дополнительных карточек и не меняет статус.

## Правило будущих изменений

Сначала меняется этот конструктор или его версия, затем один раз проверяется конкретный сценарий. Нельзя добавлять отдельные каскадные форматы карточек поверх предыдущего. Текстовые шаблоны и рассылки изменяются отдельно от визуального конструктора.

## Текущий результат 060

Результат интервью на продуктивность фиксируется оператором. Для дальнейшей рассылки виден маленький значок ✉ без отправки кандидату. Существующие статусы, слоты, фильтры, сообщения, группы, брифы и другие этапы не изменяются.
