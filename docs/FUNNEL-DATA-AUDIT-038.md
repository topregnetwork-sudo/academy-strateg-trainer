## Напоминания — независимо от города

Любая действующая запись получает напоминание и бриф за 30 минут: Минск, Челябинск, любой будущий город. Город ограничивает приглашение на конкретную встречу, но не доставку напоминания записанному. Отменившим участие и завершившим этот этап устаревшие напоминания не отправляются.

Три сохраняемые схемы хранения: первое Zoom-собеседование (`candidates`), прежняя запись Минск 1 сентября (`offline_interview_bookings`, теперь онлайн), конструктор будущих встреч (`funnel_bookings`). Для каждой создаётся точная задача, а не новый постоянный обход кандидатов. При ошибке назначение сохраняется с ошибкой; автоматическая повторная доставка неоднозначно отправленных сообщений не допускается.

## Что нельзя восстановить задним числом

- Старые URL-кнопки Zoom не передавали нажатия боту. Их дата не подменяется датой записи.
- Для тех, кому Анкета 2 была отправлена до включения защиты, доступ сохраняется без выдуманного нажатия. Новым такой обход недоступен.
- Если тест завершён раньше первого зафиксированного нажатия, срок не вычисляется.
- Цели — страница и PDF в приглашении; факт отправки ссылки не доказывает изучение. Текст целей и брендовые материалы не изменялись.
- Статус задачи «обработка завершена» не означает прочтение Telegram: при отмене записи задача может завершиться без отправки. Доставку сверять по сообщениям.

## Контроль оператора

Откройте кандидата → ответ «Вы такой человек?» → время нажатия первого Zoom → Анкета 2 и Тест 1 → отправленное приглашение и выбранное время → задачи напоминания → фактическая переписка. Все решения по продуктивности остаются ручными.

Проверка production: 31 запись на первое Zoom (31 августа — 14, 1 сентября — 9, 2 сентября — 3, 3 сентября — 4, 4 сентября — 1). Назначены пять задач напоминания/брифа и пять задач контроля неявки. Для шести занятых слотов разбора 1 сентября назначены шесть напоминаний/брифов: 10:30, 11:30, 12:15, 12:30, 12:45, 13:00 МСК. Во всех 16 задачах параметры — объекты, состояние pending, ошибок назначения нет. Перевод на точные таймеры подтверждён; старый перебор больше не используется.

Исправлен производственный дефект двойного JSON-кодирования параметров (шесть прежних задач исправлены без изменения дат). Новые задачи и настройки конструктора сохраняются объектами. В 31 существующем подтверждении заменена только кнопка на фиксируемый вход. Внешних тестовых напоминаний не рассылали; фактическая доставка проверяется после наступления времени. HTTP страницы целей и PDF — 200.

Новые/повторно синхронизированные карточки Drive используют тот же отсчёт от Zoom. Старые документы массово не перезаписывались. Полного визуального просмотра в браузере не было: выполнены DOM-тесты сохранности полей и API/SQL-проверки.
