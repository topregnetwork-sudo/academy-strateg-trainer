# Реестр подключений Академии Стратег

Последняя сверка: 3 сентября 2026, Europe/Moscow.

Этот файл — единая карта подключений проекта. В нём не хранятся токены, пароли,
private keys, cookies или содержимое credential-файлов. Старая запись в памяти
считается исторической, пока её состояние не подтверждено свежей проверкой.

## Секретные хранилища, обнаруженные локально

Найдена отдельная папка `C:\Users\admin\Downloads\Academy_Strateg_SECRETS_LOCAL_ONLY`.
Она содержит ссылки/credential-файлы для Google Sheets readonly, n8n и HMAC
платформенного webhook. Содержимое файлов не переносилось в проект, не выводилось
в отчёты и не коммитилось. Рабочий проект использует только имена переменных и
внешние secret stores.

В текущем профиле отсутствуют локальные каталоги `.vercel`, `.wrangler` и
`.config\wrangler`. Поэтому «войти в Cloudflare/Vercel в браузере» и «иметь
CLI-подключение для деплоя» — разные состояния.

## Что восстановлено и что ещё не восстановлено

В исходниках сохранены все основные точки интеграции: GitHub/Pages, Vercel API,
Cloudflare Worker, Telegram webhook, Google Drive bridge, storage и номенклатура
служебных подключений. Проверены ответы HTTP основных публичных доменов.

Не подтверждено свежим CLI-сеансом:

1. авторизация Vercel CLI;
2. авторизация Wrangler CLI;
3. успешный live-запрос к Apps Script bridge из текущей среды — TLS-соединение
   среды завершилось ошибкой до получения ответа приложения;
4. свежая проверка n8n API и Telegram Bot API без использования секретов.

Это не означает, что пользователь вышел из браузера или что рабочие credentials
удалены. Это означает только, что их нельзя безопасно считать доступными текущим
терминальным процессам.

## Правило дальнейшей работы

Перед точечной доработкой читать этот реестр и `state.json`, затем проверять только
затронутый узел. Не выполнять повторный аудит всей воронки без отдельной причины.
Сначала проверять: исходник → конфигурацию → живой endpoint → фактический event.
Секреты не извлекать и не печатать. Любое изменение записывать в
`change-ledger.md`, а перед изменением создавать точную rollback-ветку.

## Одноразовое восстановление CLI, если потребуется деплой

Браузерный вход не переносится в терминал автоматически. Если понадобится именно
публикация из терминала, пользователь один раз запускает интерактивный вход:

```text
npx vercel login
npx wrangler login
```

После этого можно выполнять деплой из соответствующего каталога проекта. Для
автоматического CI-подключения потребуются секреты репозитория Vercel и Cloudflare;
их значения в этот файл добавлять нельзя.
