# INTERVIEW-APPOINTMENT-048 — запись и итоговый образец

Production baseline db8188316468a19fc5fb9af71153e29686467123 не изменён. Подготовка 047 остаётся неопубликованной. Код 048 проверен в preview; флаг INTERVIEW_APPOINTMENT_048 по умолчанию выключен до обновления облачного моста.

## Сделано

- readProductivityAppointment читает сохранённую запись одного кандидата из offline_interview_bookings (текущая минская кампания 2026-09-01) или funnel_bookings + funnel_slots + funnel_sessions. Никаких скриншотов и перебора всех кандидатов.
- После записи/переноса, отмены, создания досье ставится адресная задача обновления существующего бланка. Задача повторно читает актуальную запись под блокировкой кандидата. Отдельный вызов моста обновляет только F9/F10/F11/F12, не создаёт файлов и не экспортирует Тест 1.
- Мост сохраняет ручные изменения и формулы, отслеживает прежние автоматические значения; повторный вызов не дублирует файл. Несколько бланков в папке — ошибка, не случайный выбор. Отсутствующий бланк — адресная ошибка задачи, успешная бронь не отменяется.
- Пример https://docs.google.com/spreadsheets/d/1ZcQLAQ3062CwyY4Cqud_6NJkMCZptPzsYMvcd9VksDk/edit обновлён из рабочей БД через ограниченный read-only preview endpoint. Лось Алексей, ID 94, запись legacy:94:2026-09-01:1115. Дата/время не из скриншота. Ведущий — явная настройка утверждённой кампании, а не распознавание Zoom.
- В этом же образце блок Итог!B66:L102 перенесён на «Финал»!B5:L41; Итог!B48:L64 — на «Анкета 2 — сведения»!B5:L21. После проверки копий исходные блоки убраны с «Итог». Ответы, примечания, объединения и размеры строк сохранены нативным копированием. Остальной бланк не переделан.
- Добавлен «Сроки воронки»: фактические события из рабочей БД, дата/время МСК, от предыдущего события и от первого квалифицированного нажатия входа в Zoom. Плановое интервью не включено в фактическую длительность. Конец не определён, дату и суммарный окончательный срок не выдумывать. Краткая сводка на Начало!B90:L94.

## Проверено и границы результата

17 локальных тестов: источник времени, изменение слота, отмена, ручные поля, формулы, повтор, Q1/Q2-only, основные регистрации/отправки/вместимость. Preview Vercel успешен. Рабочая база прочитана только по одному кандидату. Образец обновлён Google Sheets connector, затем перечитан. Это проверка чтения БД → заполнения образца, НЕ доказательство автоматического вызова нового Apps Script в production.

Нет доступного инструмента редактирования/публикации Apps Script в этой сессии. Code.gs содержит готовое действие appointment048, но облачный deployment не обновлён. Production-флаг не включать до проверки capability и одного вызова без отправки сообщений.

Перед общим запуском синхронизировать чистый шаблон и mapper с последней утверждаемой структурой: Начало F14/F15/F16/F17/F18, B38/B41; дополнительные сведения теперь на отдельном листе, прежний sentinel Итог!B48 больше не подходит. Текущий чистый шаблон 047 ещё старый; не выдавать готовый образец за массовое обновление шаблона. Сроки воронки сейчас заполнены в образце; их событийная массовая синхронизация ещё не подключена.

## Сохранность / откат

Не менять анкеты, результаты тестов, статусы, сообщения, слоты, напоминания, членство. В production ничего из 048 пока не откатывать — оно не выпускалось. Для отключения при будущем запуске INTERVIEW_APPOINTMENT_048=false; при этом старый путь остаётся прежним. До активации создать rollback-ветку от актуального production. Не откатывать всю 047 или данные кандидатов.

Образец имеет префикс «Образец 048», чтобы не совпадать с поиском рабочего бланка. Облачный исходный бланк кандидата не изменён. История Google Sheets сохраняет изменения; для отката перестановки переносить только два добавленных блока обратно, не удалять ответы.
