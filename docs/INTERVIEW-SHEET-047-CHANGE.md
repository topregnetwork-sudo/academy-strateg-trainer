Существующий событийный момент создания папки и отдельная выгрузка теста остаются прежними; эта корректировка не пересоздаёт облачные файлы и не выпускает production.

Существующий бланк найден по папке — заполняются только пустые поля; галочки, выводы и ручные ответы неприкосновенны.

Код моста должен быть обновлён и опубликован в существующем Apps Script deployment. Затем проверяется capability interviewSheet047 и только после этого разрешено выпускать серверную часть. До этого production не переключать. Нельзя считать сохранённый Code.gs обновлённым облачным мостом.

## Проверка

1. Источник содержит цели, достижения, доход с валютой/сроком, контакты и остальные ответы — совпадают соответствующие ячейки.
2. Вторая обработка возвращает тот же ID; ручное значение не изменяется.
3. Нет отдельной новой карточки/Анкеты 2, старые файлы на месте.
4. Тест 1 остаётся отдельной таблицей.
5. Формулы, галочки и шаблон не изменены; неизвестные данные не выдуманы.
6. Нет отправок кандидатам и изменений статуса.

Откат подготовки: отменить только изменения 047; новые облачные бланки перечислены в манифесте и не удаляются автоматически. При откате опубликованного кода оставлять старые и новые файлы и все ответы. Массовое восстановление/очистка папок запрещены.
