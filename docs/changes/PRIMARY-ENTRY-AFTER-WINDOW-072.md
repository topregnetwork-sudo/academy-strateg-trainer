# Первичное собеседование: закрытие Zoom-кнопки после начала — 072

Статус: `fixed_deployed_verified`.

## Решение

Для кнопки «Открыть Zoom» установлен единый интервал действия: от `−60` минут до `+10` минут относительно назначенного времени встречи. Например, для встречи в 08:00 МСК кнопка действует с 07:00 до 08:10 включительно.

После 08:10 старое нажатие не выдаёт новую Zoom-ссылку и не записывает событие входа. Telegram показывает кандидату, что окно завершено и при необходимости нужно выбрать новую запись. Возможность повторной записи после пропуска, которая открывается через 60 минут, не менялась.

## Сохранено

Проверка слова «кандидат», уже записанный вход в Zoom, группы, анкеты, тесты, статусы, брифы, таймеры и история сообщений не изменялись. Никаких сообщений кандидатам при публикации не отправлялось.

## Проверка

- `node --check` для изменённых модулей — пройден.
- `git diff --check` — пройден.
- Синхронизированы обработчик кнопки, восстановление старых системных ссылок, контроль неявки и временная линия карточки.
- Уже сохранённое событие Евгении в 07:33 при встрече в 08:00 остаётся действительным: оно находится внутри нового окна `−60/+10`.

## Откат

Перед изменением опубликована ветка `rollback/primary-entry-after-window-before-072` от production baseline `37a2fea`. Откат только кода выполняется через `git revert` коммита 072 и публикацию `main`; историю кандидатов и уже сохранённые события не удалять.
