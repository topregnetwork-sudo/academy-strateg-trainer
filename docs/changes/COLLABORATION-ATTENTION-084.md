# COLLABORATION-ATTENTION-084

Дата: 2026-09-09.

Область: только воронка тренеров Академии Стратег.

## Что изменено

- Опытные тренеры отделены от проверенного кадрового резерва.
- На доске добавляется отдельная колонка `Сотрудничество`.
- `Кадровый резерв` остаётся для кандидатов, которых уже проверили на интервью на продуктивность.
- Ответ опытного тренера `Да, интересно` переводит кандидата в статус `collaboration`, а не в `talent_pool`.
- Ответ `Нет, спасибо` переводит кандидата в существующую неактивную ветку `rejected`.
- Для опытных тренеров и кандидатов, оставшихся на ручном внимании после входящих сообщений, добавлен контроль 3 дня без ответа.
- Старые зависшие кандидаты могут получить персональное сообщение `Спасибо, что подождали...` с корректным следующим действием.

## Сохранено

- Основная воронка без опыта: Анкета 1 → первичный Zoom → группа → Анкета 2 → Тест 1 → продуктивность.
- Кнопки доски `Прошёл` / `Не прошёл` как событийные действия.
- Логика кадрового резерва после `Не прошёл продуктивность`.
- Исключение из группы для тех, кто не продолжает отбор.
- Google Drive, анкеты, Тест 1, расписание продуктивности, темы логов и существующие карточки.
