# PRODUCTIVITY-RESERVE-COPY-065 — Ценное приглашение в кадровый резерв

Статус: `implemented_no_live_candidate_delivery`.

## Основание

Пользователь отметил, что сухое предложение кадрового резерва не передаёт ценность кандидата. Нужен короткий, уважительный текст без формулировки «не прошёл», который благодарит за интерес к Академии, подчёркивает общность цели и сообщает о приоритете дальнейшего контакта с уже познакомившимися с Академией людьми.

## Изменено

- только текст первого личного предложения кадрового резерва;
- только текст подтверждения после ответа `Да`;
- короткий текст после ответа `Нет` тоже сделан уважительным и благодарным.

## Сохранено

- событие запуска: только нажатие оператором `Не прошёл`;
- кнопки `Да, в кадровый резерв` и `Нет, спасибо`;
- статусы `productivity_failed`, `talent_pool`, `rejected`;
- запись в тему 1073 только после согласия кандидата;
- отсутствие массовых отправок и отсутствие отправки новых сообщений уже существующим кандидатам;
- предыдущие этапы, расписание, Анкета 2, Тест 1, Google Drive и история переписки.

## Проверка

- синтаксис Telegram-обработчика и модуля сообщений пройден;
- 7 целевых и регрессионных проверок прошли;
- реальному кандидату новая версия сообщения не отправлялась.
