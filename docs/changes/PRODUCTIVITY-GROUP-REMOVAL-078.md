# PRODUCTIVITY-GROUP-REMOVAL-078 — немедленное исключение из активной группы

Дата: 8 сентября 2026 года  
Контур: только воронка тренеров Академии Стратег

## Утверждённое правило

- Оператор нажимает `Не прошёл` → кандидат сразу исключается из группы текущего отбора.
- Кандидат нажимает `Не актуально` после результата `Прошёл` → кандидат сразу исключается из группы текущего отбора.
- Кандидат нажимает `Спасибо` → остаётся в группе; статус `productivity_passed` сохраняется.
- Для исключения не требуется ждать ответа кандидата по кадровому резерву.
- Согласие на кадровый резерв продолжает обрабатываться отдельно; уже выполненное исключение повторно не выполняется.

## Реализация

Общая операция Telegram вынесена в `candidate-group-removal-078.js`. Она проверяет группу, читает фактический статус участника, не трогает уже вышедшего кандидата и защищённых администраторов, исключает обычного участника через `banChatMember` и сразу снимает бан, после чего повторно проверяет результат.

Состояние сохраняется в `candidate_productivity_outreach`:

- `removed` — исключение подтверждено Telegram;
- `already_outside` — кандидат уже был вне группы;
- `attention` — Telegram не подтвердил действие или группа не настроена.

Оператор видит это состояние в карточке кандидата. При `attention` повторная обработка того же события пытается выполнить исключение ещё раз, а ошибка остаётся видимой для проверки.
