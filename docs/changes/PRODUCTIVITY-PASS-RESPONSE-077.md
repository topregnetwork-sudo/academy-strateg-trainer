## Запрос

После результата «Прошёл продуктивность» кандидат получает короткое сообщение с двумя кнопками:

- «Спасибо» — сохранить кандидата в маршруте `productivity_passed`;
- «Не актуально» — перевести кандидата в `rejected`.

Внутренний образец в теме должен повторять кандидатское сообщение без служебной обёртки.

- После «Не актуально» отправляется подтверждение, сохраняется статус `rejected` и событие перехода.
- Тестовый маршрут отправки образцов использует ровно `PRODUCTIVITY_PASS_MESSAGE` и `PRODUCTIVITY_RESERVE_MESSAGE` с их рабочими кнопками.
